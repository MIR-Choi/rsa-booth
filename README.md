# RSA 암호 해독 체험관

소인수분해가 얼마나 어려운지 직접 체험하면서 RSA 암호가 왜 안전한지 알아보는 동아리 부스용 웹사이트입니다.

| 단계 | 내용 |
| --- | --- |
| 1. 암산 도전 | 두 자리 소수 × 두 자리 소수 = N 을 암산으로 소인수분해 (옆에 두 자리 소수 목록) |
| 2. 계산기 도전 | 2~3자리 소수 × 3자리 소수 = N 을 계산기로 소인수분해, 시간·시도 횟수 기록 (옆에 두~세 자리 소수 목록) |
| 3. 컴퓨터 도전 | 난이도(6자리 · 10~12자리 · 600자리 · RSA-8192)마다 정해진 예시(15 · 15 · 4 · 4개) 중 하나를 무작위로 뽑아 컴퓨터가 소인수분해 (소요 시간, 나눠 본 횟수, 해독 가능 여부, 결과, 사람이라면 걸릴 시간) |
| 4. 암호문 해독 | 공개키와 암호문 3개만 보고 N 을 분해해 개인키를 만들어 모두 해독, 해독 과정을 숫자 표로 보여 줌 / 직접 암호문 만들기 |

## 사용 언어

- **Python**: 모든 계산과 화면 동작 (`py/` 폴더)
- **HTML**: 화면 구조 (`index.html`)
- **CSS**: 디자인 (`style.css`)

JavaScript는 직접 쓰지 않습니다. [PyScript](https://pyscript.net)가 브라우저 안에서 파이썬을 실행해 주기 때문에,
서버 없이 GitHub Pages에 그대로 올릴 수 있습니다.

## 폴더 구조

```
index.html        화면 구조 (4개 단계)
style.css         디자인 (검정 배경 + 민트/파랑 포인트)
pyscript.toml     파이썬 파일 목록 (새 .py 파일을 만들면 여기에도 추가)
py/
  main.py         시작 파일 — 탭 전환, 각 단계 준비
  rsa_math.py     소수 만들기, 소인수분해, RSA 암호화/복호화 (순수 파이썬)
  rsa_examples.py 3단계 예시 (p, q) 목록 — 레벨 1·2는 15개씩, 레벨 3·4는 4개씩
                  (레벨 4는 OpenSSL로 미리 만든 실제 8192비트 RSA 키)
  dom.py          화면을 다루는 도우미 함수
  stage1.py       1단계 암산 도전
  stage2.py       2단계 계산기 도전
  stage3.py       3단계 컴퓨터 도전
  stage4.py       4단계 암호문 해독
```

## 내 컴퓨터에서 실행하기

`index.html`을 더블클릭하면 **작동하지 않습니다** (브라우저 보안 때문에 파이썬 파일을 못 읽어요). 간단한 서버를 켜야 합니다.

1. VS Code에서 이 폴더를 엽니다.
2. 터미널(`Ctrl + ``)에서 실행:
   ```
   python -m http.server 8000
   ```
3. 브라우저에서 <http://localhost:8000> 접속
4. 끝낼 때는 터미널에서 `Ctrl + C`

(VS Code의 **Live Server** 확장을 설치했다면 `index.html` 우클릭 → *Open with Live Server* 도 됩니다.)

수학 함수만 따로 확인하고 싶으면: `python py/rsa_math.py`

## GitHub Pages에 올리기 (git 설치 없이)

1. GitHub에서 새 저장소(repository)를 만듭니다. 예: `rsa-booth` (Public)
2. 저장소 화면의 **Add file → Upload files** 를 누르고, 이 폴더 안의 파일과 `py` 폴더를 통째로 끌어다 놓은 뒤 **Commit changes**
3. 저장소의 **Settings → Pages** 에서
   - Source: **Deploy from a branch**
   - Branch: **main**, 폴더 **/(root)** → **Save**
4. 1~2분 뒤 `https://<내아이디>.github.io/rsa-booth/` 주소로 접속

## 부스 운영 팁

- 화면 크기에 맞춰 글자와 칸이 함께 커지고 작아져서, 노트북·모니터 어디서든 각 단계가 스크롤 없이 한 화면에 들어옵니다.
  (폭이 1000px보다 좁은 화면에서는 세로로 쌓이고 스크롤됩니다.)
- 주소 끝에 `#stage-1` ~ `#stage-4` 를 붙이면 그 단계가 바로 열립니다.
  모니터가 여러 대라면 화면마다 다른 단계를 띄워 두세요. 예: `.../rsa-booth/#stage-3`
- 처음 접속할 때 파이썬 엔진을 내려받느라 5~10초 걸립니다. 부스 시작 전에 미리 한 번 열어 두세요.
- **인터넷 연결이 필요합니다** (PyScript와 글꼴을 인터넷에서 불러와요).

## 설정 바꾸기

각 파일 위쪽의 대문자 변수를 고치면 됩니다.

| 파일 | 변수 | 의미 |
| --- | --- | --- |
| `stage1.py` | `PRIME_RANGE` | 1단계 소수 범위 (기본 11~97) |
| `stage2.py` | `P_RANGE`, `Q_RANGE` | 2단계 두 소수의 범위 |
| `stage3.py` | `TIME_LIMIT` | 600자리 · RSA-8192 를 몇 초 동안 시도하고 포기할지 (기본 10초) |
| `stage3.py` | `LEVELS` | 난이도 목록과 설명 문구 |
| `rsa_examples.py` | `LEVEL1` ~ `LEVEL4` | 3단계 예시 (p, q) 목록. 줄을 지우거나 새 소수 쌍을 넣으면 그대로 반영돼요 |
| `stage4.py` | `CIPHER_COUNT` | 한 번에 보여 줄 암호문 개수 (기본 3개) |
| `stage3.py` | `HUMAN_SECONDS` | 사람이 계산기로 한 번 나누는 데 걸린다고 가정한 시간 |
| `stage4.py` | `SECRET_MESSAGES` | 4단계에서 무작위로 나오는 비밀 메시지 목록 |
